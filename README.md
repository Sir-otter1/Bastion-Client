# Bastion Client

A powerful Roblox Bedwars client with advanced features and anti-cheat compatibility.

## Features

### Visuals
- **ESP**: Boxes, Names, Health, Distance
- **Tracers**: Customizable thickness and colors
- **Chams**: See-through players with custom materials

### Mobility
- **Speed**: Multiple modes (Normal, Bhop, Strafe)
- **Flight**: Normal, Jetpack, and Glide modes
- **NoFall**: Cancel or fake fall damage
- **HighJump**: Enhanced jump height
- **NoClip**: Partial and full no-clip
- **AntiKnockback**: Reduce knockback damage

### Utility
- **AutoArmor**: Automatically equip best armor
- **AutoTool**: Switch to best tool automatically
- **ChestSteal**: Automatically steal from chests
- **AutoBed**: Break and place beds automatically
- **AutoSword**: Switch to sword in combat
- **InventoryManager**: Sort and manage inventory
- **Bridging**: Advanced bridging techniques

### Combat
- **KillAura**: Attack nearby enemies automatically
- **Aimbot**: Silent, Lock, and Smooth modes
- **Targeting**: Customizable target selection
- **Criticals**: Jump and Packet critical modes
- **Reach**: Extended attack range
- **Velocity**: Knock enemies back
- **AutoClicker**: Custom CPS with jitter
- **AntiBot**: Filter out bot players

### Anti-Cheat
- **Raycast Detection**: Advanced raycast filtering
- **Human Behavior**: Simulate human movements
- **Rate Limiting**: Prevent detection
- **Random Delays**: Add human-like timing
